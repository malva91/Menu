# Assets

Questa cartella contiene le risorse statiche dell'applicazione.

## Struttura

- **images/**: Immagini e icone
- **fonts/**: Font personalizzati (se necessari)
- **icons/**: Icone SVG
- **data/**: File di dati statici

## Convenzioni

- Utilizzare formati ottimizzati per il web
- Nomi file descrittivi e in kebab-case
- Organizzare per tipo di risorsa
