# Components

Questa cartella contiene i componenti riutilizzabili dell'applicazione.

## Struttura

- **UI Components**: Componenti base dell'interfaccia utente
- **Layout Components**: Componenti per il layout (header, footer, etc.)
- **Feature Components**: Componenti specifici per funzionalità

## Convenzioni

- Ogni componente dovrebbe essere autocontenuto
- Utilizzare nomi descrittivi per i file
- Includere documentazione per componenti complessi
